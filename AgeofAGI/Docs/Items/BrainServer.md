# 缸中之脑

基于本机游戏 0.46D。物品 ID 为 `age_of_agi.brain_server`，机器类别，初始价格 3000，由 `Data/items.csv` 初始化。存活/死亡分别使用 `brain_server.png` / `brain_server_dead.png`，死亡图仅改变外观，保留原来的占格、旋转和位置，不注册第二件物品。

`Data/Definitions/machines.csv` 配置每日电量（24）；`Data/Definitions/brain_server.csv` 配置有效算力（200）、内存（1024GB）及每日用水（200ml）。配置在注册批次加载，不在创建实例时读取。

| 存储索引 | 槽位 |
| --- | --- |
| 0 | 电池 |
| 1 | 血液 |
| 2 | 原版液体容器 |
| 3 | 网络交换机 |
| 4 | 输入（4×4） |
| 5 | 数据容器 |
| 6 | 输出（4×4） |

没有 CPU、GPU、内存或 AI 实体槽，也不创建独立基因数据栏。`BrainServerHelper` 是初始化与加载入口，`MachineRuntime` 使用显式 `BrainServer` 模式复用现有生产事务，`BrainServerLifeSupport` 负责维生与固定硬件。

## 每日维生与永久死亡

每天原生机器结算先处理维生，再选取本地任务及分布式供给服务器。空闲、输出满、缺少输入、数据容器缺失、网络中断和任务暂停均照常消耗维生资源。每天仅支付一次电量，生产和网络供给不再额外收取该机器电费。沿用共享网络的保存日标记；原生「仅机器」调试动作可在同一天开启新一轮结算。

血液槽只接受单件、玩家拥有且足够当晚用量的原版 `blood_bag` / `blue_blood_bag`。两种血袋初始容量均为 1000ml，每天消耗普通血液 500ml 或蓝血 50ml。最后一次足量供给支持当天存活与工作，耗尽后销毁血袋，下一次结算供血不足才会死亡。换出的半袋保留剩余毫升数；禁止半袋堆叠，防止与新血袋合并后补满。`AGE_OF_AGI_BLOOD_AMOUNT` 保存剩余毫升数，标签分别显示“普通血液：{0}/1000 ml”和“蓝血：{0}/1000ml”。

血袋创建补丁明确绑定 `DirectoryMaster.Item(string, bool)`；原版同时存在泛型 `Item<K>(K)`，只指定方法名会使 Harmony 在加载阶段抛出 `AmbiguousMatchException`。行为检查覆盖显式重载解析，并读取本机 DLL 元数据核对实际签名。

液体槽接收玩家拥有的单件原版液体容器。维生按 `WaterHelper.GetWaterPurity` 的真实纯度判定，至少达到原版优质水阈值 9900（99%），且体积足够每日用量；不读取可编辑的公开水质标签。通过原版 `WaterHelper.RemoveMl` 扣除液体，保留空容器。

任一供给不足时保存 `AGE_OF_AGI_BRAIN_DEAD` 和死亡原因，切换死亡图，永久停止工作、供给与维生消耗，释放任务锁以取回物品。没有维修或复活操作，补充资源及保存/读档不能复活。供给检查失败时不部分扣除其他资源。

状态标签仅显示简短状态：水不足或真实水质不合格为“缺水”，电量不足以支持当晚为“缺氧”，血液不足当晚用量为“缺血”，死亡后为“已死亡”。标签不显示每日消耗、纯度阈值或维修规则等说明文本。

## 本地生产与分布式供给

本地支持 BTC 与配置解码配方、情报、各级载体数据抽取。配方工作量继续读取现有服务器与解码配置。无需训练或消耗 AI，不生成隐藏 AI。生产状态通过 `Intrinsic` 标记绑定机器身份，保存冻结源物品、任务权限、工作预算、进度及数据/基因快照。生物生产底层逻辑保留，基因选择界面方案待定，不创建栏位或替代入口，也不自动选择基因。

情报仍需要交换机的网络访问与数据伪装升级；本地载体抽取无需交换机。输出容量、数据容器可替换、源载体空壳、溢出丢弃和交付事务沿用现有规则。

通过安装高速连接升级的交换机配对后，可以作为现有分布式终端的供给服务器。本地可执行任务优先；无本地任务时按原有独占调度提供固定基础算力与内存。终端应用自身 AI 倍率和耐久规则。死亡机器不再提供资源。

## 验证与生成

F9 → Spawn → `Spawn brain_server` 生成裸机；需要在下一次机器结算前装好电池、血液与水。没有新增商人或掉落来源。

`BrainServerChecks` 使用独立配置（与上述实际参数不同）和生成素材，覆盖两种血袋逐日毫升扣除、末次使用、不足当晚血量、禁止部分堆叠、真实水质边界、缺少维生资源、永久死亡、空闲收费、本地生产、交付回滚、基因入口待定时不自动选取、分布式供给/本地优先、死亡释放锁、禁用/重启用及当前格式恢复。Release 构建引用本机 0.46D 程序集。

游戏内机器窗口布局、血袋提示、真实液体混合、贴图切换及真实存档加载仍需重启后在可丢弃的测试存档中手动验证。
