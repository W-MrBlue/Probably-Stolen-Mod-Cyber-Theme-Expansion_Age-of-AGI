# 本地化源表

游戏基线：0.46D。所有表为UTF-8、无表头，每个物理行一条`key,value`；`#`开头的行是注释。

- `en.csv`、`zh.csv`：物品、分类、机器和其他UI文本。
- `Npcs/en.csv`、`Npcs/zh.csv`：NPC名字和对白。每位客人的名字后紧跟该客人的开场／成交对白，按variant成对排列。普通商与其不诚实变体共用名字和对白组，拾荒者及其不诚实变体同理。
- `Books/en.csv`、`Books/zh.csv`：纸张书籍正文、标题和图注。Paper JSON 的显示文字仅通过 `loc` 引用这里的键，不内嵌 `text` 或 `translations`；同一本书共用的标题和署名复用键。
- NPC表末尾集中保存共用预算句、显卡质疑回应及已停用客人的原有文本。停用文本不会自动启用来访。
- 网络服务标题、描述和已购买提示仍属于UI，保留在主表。

## 构建与部署

原版只扫描`Localization`直属CSV，并将文件名当作语言代码。`Build/Localization.targets`的`MergeModLocalizations`在每次构建时按主表、NPC表、书籍表的顺序合并同语言内容，输出到`bin/<配置>/netstandard2.1/Localization/<语言>.csv`；部署复制合并结果到`Mods/AgeofAGI/Localization`。NPC和书籍分表可缺省，不直接部署这两个子目录，也不覆盖源码主表。`DeployModOnBuild=false`仍会生成合并表，只跳过游戏Mod目录部署。

修改任一源表后重新构建并重启游戏。不要编辑生成表。同语言重复键会中止合并，并报告两个来源的位置；文本内容、引号、分号和字面`\n`保留给原版解析。

显卡指南的键统一以`book_gpu_guide_`开头。书籍根`title`和页面`name`是编辑器标识，原生格式没有对应的本地化字段，因此使用固定标识；玩家看到的标题属于文本元素，使用`loc`。新增书籍文字时同时补齐中英文分表。书籍 JSON 的重载不会重载语言 CSV，更新文字后需构建并重启游戏。

## NPC对白映射

模组对白统一经 `ClientDialogueText` 处理：仅中英文分号分隔气泡，其余标点和段内空白保持原文。独立的 `... ...`、`......`、`……` 以及「呼......」「当然......」均不额外拆分。夜班、其他供应商和剧情对白遵循同一规则，不合成停顿节点、不跳过打字。省略号逐字等待及句末阅读、选择、结束和事件等待均沿用原版，不再覆盖等待时序。显式停顿写作字面 `\p`，编译为原生 `<waitfor=1>`，默认等待1秒，可写在一句之中或句末，例如 `呼......\p；接下来再说`。它使用原生打字器动作，遵循原版逐字开关和玩家跳过操作；不添加协程或额外气泡。供货等回调仍绑定完整链尾。

客人ID到对白的绑定维护在`Data/client_dialogues.csv`，列为：

```csv
client_id,variant,greeting_key,deal_complete_key
```

同一客人可以添加多个正整数variant；创建该次来访时等概率选择一行，同一行的开场和成交对白配对。variant不要求连续，不能重复。新增一套对白时，在中英文NPC表对应客人的名字下增加文本键，再增加映射行。

`greeting_key`必填；`deal_complete_key`留空则沿用客人原生成交对白和回调。填写后保留完整成交链，并在末段调用原生`OnDealAccepted`。只有收购商入口追加实时预算，供货商和剧情客人不追加。英文或中文分号分隔气泡；供货、介绍和离场动作绑定在开场最后一段。

所有当前模组客人工厂（包括尚未启用的模型工程师）都通过映射选取开场。普通／不诚实普通商、高级硬件商、显卡供货商、退休电子商人和夜班各提供三套开场，模型工程师提供两套。拾荒者及其不诚实变体各有十套，扒手和小偷各有五套，新增部分使用核对过中英文实际内容的原版通用片段；筛选来源见[拾荒者与小偷](../Npcs/Electronics/Salvage.md)。五组电子市场事件的14名买家／卖家各有一套中英文开场，收购商继续附加实时预算句，卖家不附加。未知女孩保留既定的一句剧情开场，今后可在明确剧情设计后扩展。

`@native:原版对白键`会调用`LocHelper.GetLocalizedDialogue`获取游戏对白文字，不执行原版对白附带的供货动作。`@native:原版键1;原版键2`依次读取多句，中文分号亦可；空段和键首尾空白被忽略。每句按原顺序显示，供货仍绑定到整条链的末段。此语法适用于映射中的开场和成交键所指向的文本；引用内全部片段必须是原版键，普通对白无需此前缀。

构建合并的独立样例检查：`& .\Modding\Tests\LocalizationBuildChecks.ps1`。默认行为检查不依赖本目录可编辑内容。
