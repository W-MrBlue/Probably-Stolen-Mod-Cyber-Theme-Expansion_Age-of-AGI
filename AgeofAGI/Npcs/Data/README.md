# 企业计算服务商

基线为本机游戏0.46D，实现为`Npcs/Data/DataBuyers.cs`，与综合电子收购人和电子产业周商独立。

普通数据工程师、高级数据工程师和云服务商已合并为唯一买家`age_of_agi.enterprise_computing_service`，中文名“企业计算服务商”。不再保留三档同名单买家、145/350价值分档或旧ID的F9入口。

## 来访与收购

- 仅由橱窗的`data_container`分类吸引，不加入`generalPool`，不要求电子产业服务。
- 沿用原版橱窗分类价值排序及访客数量；任一状态有效、可转售的容器即可匹配企业计算服务商。
- 复用`CreateHospitalAdmin`的上层阵营、形象、预算及原生修正，不额外增加天数或吸引力门槛。
- 只收购普通／高容量解析数据容器，空、部分装满、全满均可；价格包含壳价与实际数据价值。
- 拒绝无效内容、原始载体、遗传数据容器和硬件，保留`NOT_FOR_RESALE`限制。
- 交易模式为BUY，不再随访出售两个空普通容器，也不改变购买预算。空容器供货由既有周商等出售渠道负责。

## 对话与生命周期

对话映射来自`Data/client_dialogues.csv`，名字及紧随其后的对白位于`Localization/Npcs/en.csv`和`zh.csv`，构建时合并输出到原生语言表。由头按分号逐句显示，最后一段通过`electronics_buyer_available_credits`实时报告剩余预算；成交对白保留完整气泡链，末段运行原生`OnDealAccepted`并询问是否还有数据容器。

注册只加入一个企业工厂和`data_container`主分类，重复注册不叠加。禁用只移除仍由本模块持有的工厂、分类和队列访问，保留其他模块替换的工厂及预先存在的分类。队列与原版一样不持久化。F9 > Spawn仅保留`enterprise_computing_service`预览入口。

独立检查覆盖空满及非法容器、原始载体排除、实时预算、不出售空容器、橱窗路由、注册启停和所有权清理。实际游戏橱窗预测、画像、交易和保存重启仍需手动核验。
