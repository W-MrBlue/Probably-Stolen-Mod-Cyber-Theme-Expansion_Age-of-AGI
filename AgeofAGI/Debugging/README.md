# F9 调试入口

游戏 0.46D 的 F9 → Spawn 栏仅注册四个 Age of AGI 入口，各自打开可搜索、滚动、拖动并按 Escape 关闭的子菜单：

- 物品生成：目录物品、Fast Grower DNA 预设、已购电子产业礼包补领。
- 事件生成：已注册的模组电子产业事件，通过原生 StoreEventManager.ActivateEvent 激活。
- 人物生成：普通买家、卖家、供货商的队首召唤。
- 剧情生成：葵拉剧情召唤与待交付剧情物品补领。

ModDebugActions 组织动作，ModDebugMenu 管理分类和窗口。重新注册或停用时清空自有动作并关闭子菜单；不修改原生分类和其他来源的按钮。动作执行前通过 PlayerStore.HasInstance 检查场景，异常使用 ModLog 记录。礼包和剧情动作继续使用原有权益、当前节点与交付判定。

构建引用本机 0.46D 程序集；独立行为检查覆盖四个入口、分类动作、搜索、重复打开、事件分发、场景未初始化与停用清理。真实游戏中的字体、滚动和窗口排版仍需实测。
