# 独立行为样例

这里的表格是测试输入，随测试程序集嵌入，不参与模组构建或部署，也不会与 `Modding/AgeofAGI/Data/` 同步。

样例覆盖价格舍入、训练与生产、概率抽样、柜台容量及状态恢复等回归场景。包括与当前模组不同的数值，例如这里的未训练 AI 系数为0.6；默认测试不读取实际模组系数。当前开发阶段无需考虑旧存档兼容性，现有历史用例可随规则调整，不要求为历史保存格式维护新用例。

`sprites.csv` 记录测试图片路径、宽高和从下向上排列的占格掩码。空掩码表示全占格。运行时生成 RGBA PNG，只作为测试替身，不是游戏美术。

新增测试必须只检查独立样例的解析、读取一致性和行为，不涉及实际可自定义配置。真实配置的合法性检查仅属于用户显式要求的独立诊断，不加入默认测试。
